### Basic Principles (For reference only; adjust flexibly based on the specific event and participating groups):

* The target user group consists of Chinese people, so the configuration must align with Beijing Time (CST) daily routines.
* 0:00-5:00 AM: Almost no activity (Activity Coefficient: 0.05).
* 6:00-8:00 AM: Activity gradually picks up (Activity Coefficient: 0.4).
* 9:00 AM - 6:00 PM (Working hours): Moderately active (Activity Coefficient: 0.7).

* After 11:00 PM (23:00): Activity declines (Activity Coefficient: 0.5).
* General pattern: Low activity in the early morning, gradual increase in the morning, moderate during working hours, and peaking in the evening.

* agents_per_hour_min (int): Minimum number of Agents activated per hour (Value range: 1-{max_agents_allowed}).
* agents_per_hour_max (int): Maximum number of Agents activated per hour (Value range: 1-{max_agents_allowed}).
* peak_hours (int array): Peak hours, adjusted according to the target groups involved in the event.
* off_peak_hours (int array): Off-peak hours, typically late night and early morning.
* morning_hours (int array): Morning hours.
* work_hours (int array): Working hours.
